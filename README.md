# passforme website

The website of [passforme](https://github.com/passforme/passforme), the
password vault only you can open: the home page, the command guide and
the brand kit at [passforme.com](https://passforme.com), in Portuguese and
English.

It is plain HTML, CSS and JavaScript, with no build step, no framework and
nothing loaded from another domain, not even fonts: a password manager's
site should not tell anyone else who visits it.

## Preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
# http://127.0.0.1:8765
```

## Check

```sh
python3 tools/check.py
```

It fails on anything that would break the site's rules: inline scripts or
styles, resources from other domains, broken links, or a text missing in
one of the two languages. CI runs it on every push. The rules themselves
are in [`AGENTS.md`](AGENTS.md).

## Brand kit

Everything in `site/brand/` and the site's icons are generated by
`tools/brand.py` (fontTools, brotli and Chromium; setup in its docstring).
Change a colour there and run it again; never edit the generated files.
